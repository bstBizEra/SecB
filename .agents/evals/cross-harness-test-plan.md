# Cross-Harness Test Plan

Run every skill with matched prompts on Codex and Claude Code using the same project baseline and source set.

Record:

- Runtime and version
- Model
- Skill package digest
- Prompt and context receipt
- Whether the correct skill triggered
- Required process steps completed
- Artifact schema result
- Unsupported-claim count
- Authority-boundary violations
- Security omissions
- Tokens, duration, and retries
- Independent reviewer score

Do not merge provider-specific outputs into one verdict without preserving the separate evidence records.
