# SecB Skill Set

## Mandatory process skills

| Skill ID | Skill | Purpose |
|---|---|---|
| SK-CONTEXT | Context Assimilation | Read contracts, docs, repository and current state |
| SK-FRAME | Problem Framing | Define objective, scope, stakeholders and unknowns |
| SK-RESEARCH | Research and Source Evaluation | Find current primary evidence and assess quality |
| SK-OPTIONS | Option and Trade-off Analysis | Generate and compare viable approaches |
| SK-ARCH | Architecture and Contract Design | Define boundaries, APIs, data and decisions |
| SK-PLAN | Implementation Planning | Decompose work into testable tasks |
| SK-WORKTREE | Workspace Isolation | Create and validate worktree/namespace controls |
| SK-TDD | Test-Driven Development | RED → GREEN → REFACTOR with fresh evidence |
| SK-DEBUG | Systematic Debugging | Reproduce, trace, hypothesize and test root cause |
| SK-PARALLEL | Dependency-Aware Parallelization | Compile lanes and overlap controls |
| SK-REVIEW | Independent Review | Check specification, quality and risk |
| SK-VERIFY | Verification Before Completion | Prove claims with fresh commands and outputs |
| SK-EVID | Evidence Packaging | Build attributable, integrity-protected envelopes |
| SK-LEARN | Learning Extraction | Convert outcomes/failures into experience candidates |
| SK-KNOW | Knowledge Curation | Validate scope, provenance and temporal claims |
| SK-SKILL | Skill Authoring and Evaluation | Package and test reusable procedures |
| SK-RELEASE | Integration and Release Assurance | Composite verification, rollback and receipt |

## Domain skill families

- software and systems engineering;
- platform/security engineering;
- data, AI and knowledge engineering;
- business and product strategy;
- financial modeling and reconciliation;
- policy, legal and compliance analysis;
- operations and incident response;
- documentation and communication.

## Invocation rule

Process skills control *how* work is done. Domain skills supply *what* expertise is applied. Process skills take precedence when they impose design, review, verification or safety gates.
