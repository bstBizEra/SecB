# ADR-0002: Runtime Products Are Not Authorities

- **Status:** Proposed / Not Effective
- **Date:** 2026-07-17
- **Decision:** Codex, Claude Code, Antigravity, CI agents, and local models are Runtime Products/Deployments. Authority derives from SecB identity, role, project, work, policy, and state.
- **Rationale:** Product name, provider, or model capability does not establish permission or accountability.
- **Consequences:** Every runtime requires a registered adapter, deployment identity, evaluation state, and revocable session authorization.
