# ADR-0003: Seven-Ledger Organizational Brain

- **Status:** Proposed / Not Effective
- **Date:** 2026-07-17
- **Decision:** Separate Work, Event, Evidence, Decision, Knowledge, Capability, and Outcome ledgers logically.
- **Rationale:** Events are not evidence; evidence is not knowledge; knowledge is not skill; process success is not business outcome.
- **Consequences:** More explicit data contracts and joins, but reduced poisoning, ambiguity, and cross-scope leakage.
