# Product Operating Model

## Product hierarchy

```text
SecB Platform
├── Agent Command Center
├── Project and Portfolio Control
├── Governed Execution Runtime
├── Live Operations
├── Evidence and Assurance
├── Memory and Context Federation
├── Knowledge and Code Intelligence
├── SkillsHub
├── MCP/A2A Federation
└── Administration, Security and FinOps
```

## Product management controls

Every product capability requires:

- target users and problem statement;
- measurable outcome and adoption hypothesis;
- module owner and technical owner;
- risk and data classification;
- architectural contract;
- delivery roadmap and version strategy;
- service levels and operational owner;
- evidence, knowledge and skill strategy;
- deprecation and migration policy.

## Product review questions

1. Which user or governance problem is solved?
2. Which current workflow or cost is improved?
3. Which evidence proves value?
4. Which risks and failure modes are introduced?
5. Which capabilities can be reused across products?
6. Which manual decisions must remain human?
