# Controlled Intake of `obra/superpowers`

**Document ID:** SECB-SKILL-INTAKE-SUPERPOWERS-001
**Version:** 1.0.0-draft
**Status:** DRAFT / CONTROLLED INTAKE CANDIDATE / NOT EFFECTIVE

## Value Proposition

The methodology provides useful process skills for:

- brainstorming and design before coding;
- implementation planning;
- worktree isolation;
- TDD;
- systematic debugging;
- subagent task isolation;
- independent review;
- verification before completion; and
- skill authoring through behavioral pressure tests.

## Governance Boundary

Superpowers is an execution methodology and candidate skill source. It does not establish SecB identity, authority, evidence acceptance, memory admission, skill publication, merge, release, or production authority.
