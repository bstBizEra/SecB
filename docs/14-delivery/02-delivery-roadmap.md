# Delivery Roadmap v0.1

## Phase 0 — Constitution and contracts

Deliver root AGENTS.md, SECB-GOV-001, canonical IDs, Project/Module/Goal/Work contracts, role matrix, risk classes, event/evidence envelopes and system-of-record boundaries.

## Phase 1 — Read-only self-pilot

Register SecB, its repository, modules, harnesses and one R0/R1 work package. Observe Codex and Claude sessions, create evidence, independent review, outcome receipt and learning candidate.

## Phase 2 — Bounded mutation pilot

Enable isolated worktree mutation for one low-risk validator. Require workspace lease, declared write set, producer evidence, independent REV/QA, immutable candidate and serialized integration.

## Phase 3 — Live Operations and adapter SDK

Implement Codex, Claude Code, Antigravity and Generic CLI adapters; browser terminal; semantic events; Git/file/test telemetry; pause, terminate and quarantine.

## Phase 4 — Evidence, knowledge and failure learning

Operationalize failure envelopes, research tasks, knowledge claims, temporal supersession and outcome-linked learning.

## Phase 5 — SkillsHub controlled pilot

Intake process skills, run baseline/skill-enabled tests, cross-harness evaluation, restricted publication and performance monitoring.

## Phase 6 — Project and portfolio scale

Add universal Project Profiles, module portfolio, dependency graph, cost/capacity governance and external PM integrations.

## Phase 7 — Federation

Add policy-gated MCP, non-escalating A2A, shared capability distribution and cross-project knowledge publication.

## Phase 8 — Production governance

Add environment promotion, progressive delivery, resilience, incident response, rollback and human release authority.
