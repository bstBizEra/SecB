# Memory and Context Federation

## Memory layers

- Session memory — temporary current execution state.
- Work memory — acceptance, findings and checkpoints for a work package.
- Project memory — durable project conventions and approved decisions.
- Organizational knowledge — approved cross-project claims.
- Procedural memory — evaluated skills distributed through SkillsHub.

## Retrieval order

1. Authority and project scope.
2. Current state and temporal validity.
3. Exact evidence and authoritative records.
4. Approved knowledge.
5. Candidate knowledge, clearly labeled and only when permitted.
6. Semantic similarity.

Memory records require immutable IDs, provenance, confidence, access policy, retention, integrity and supersession. Caller-declared authority and implicit cross-project fallback are prohibited.
