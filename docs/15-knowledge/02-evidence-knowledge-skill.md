# Evidence → Knowledge → Skill

```text
Observed event
→ Evidence candidate
→ Verification
→ Accepted evidence
→ Experience candidate
→ Lesson/knowledge candidate
→ Knowledge review
→ Approved knowledge claim
→ Skill candidate
→ Evaluation
→ Restricted pilot
→ Published skill
→ Outcome monitoring
```

## Knowledge claim contract

- claim text and type;
- project/domain scope;
- source evidence;
- current, historical or transitional status;
- confidence and uncertainty;
- valid-from, review-by and valid-until;
- contradictions and supersedes/superseded-by;
- approver and admission decision.

## Prohibitions

- transcript-to-knowledge automatic promotion;
- unsupported inference recorded as fact;
- vector similarity overriding project scope or temporal state;
- skill publication based only on author demonstration;
- skill or knowledge granting execution authority.
