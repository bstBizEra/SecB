# Work Package Lifecycle

```text
DRAFT
→ FRAMED
→ RESEARCHED
→ DESIGNED
→ PLANNED
→ AUTHORIZED
→ READY
→ RUNNING
→ CHECKPOINTED
→ PRODUCER_VERIFIED
→ REVIEW
→ QA_SECURITY
→ GOVERNANCE_DECISION
→ INTEGRATION_QUEUE
→ DELIVERED
→ OUTCOME_OBSERVATION
→ LEARNING_REVIEW
→ CLOSED
```

Exceptional but non-terminal routing states:

```text
RESEARCH_REQUIRED
REPLAN_REQUIRED
AUTHORITY_CORRECTION_REQUIRED
DEPENDENCY_RESOLUTION_REQUIRED
INCIDENT_RESPONSE_REQUIRED
QUARANTINED_PENDING_DISPOSITION
```

## Required work package fields

- identity and parent goal;
- project, product and module;
- owner, roles and harness assignments;
- risk and mutation classes;
- baseline and declared write set;
- objective, non-goals and acceptance criteria;
- dependencies and assumptions;
- allowed tools, MCP, network and credentials;
- test, review, QA and security plan;
- evidence destination;
- schedule and budget;
- rollback and recovery;
- learning obligations.
