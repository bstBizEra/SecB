# Goal System

## Goal hierarchy

```text
North Star
→ Annual Platform Outcome
→ Quarterly Product Objective
→ Key Result
→ Module Goal
→ Work Package
→ Task
→ Session
→ Outcome Receipt
```

## Goal quality standard

Every goal must specify:

- desired outcome and beneficiary;
- current baseline;
- target metric and date;
- constraints and non-goals;
- owner and decision authority;
- dependencies and assumptions;
- leading indicators;
- evidence required to close;
- failure thresholds and review triggers.

## Initial SecB v0.1 goals

### G-01 — Governed self-pilot

Prove one complete read-only and one bounded-mutation lifecycle with traceable identity, context, execution, independent review, evidence, outcome and learning.

### G-02 — Harness federation

Register Codex, Claude Code, Antigravity and one generic harness through the canonical profile and event contracts.

### G-03 — Failure-to-capability conversion

Convert at least three distinct non-success events into evidence-backed research tasks, two approved knowledge claims and one evaluated skill candidate.

### G-04 — Module delivery control

Allocate all P0 modules to accountable owners, harness lanes, acceptance criteria and integration dependencies.

### G-05 — Human operational visibility

Provide a live dashboard showing session state, agent/harness identity, commands/tools, code changes, evidence, cost, findings and intervention controls.
