# Implementation Roadmap

**Document ID:** SECB-ROADMAP-001
**Version:** 1.0.0-draft
**Status:** DRAFT / NOT EFFECTIVE

## Phase 0 — Operating Constitution and Canonical Contracts

Deliver universal ontology, Project Profiles, authority/risk/SoD, state machines, Context Receipt, Handoff Envelope, seven ledgers, evidence, policy decision, and system-of-record boundaries.

**Exit:** one read-only Work Package traces from intent to outcome using canonical identity.

## Phase 1 — SecB Read-Only Self-Pilot

Register SecB, runtime deployments, agents, roles, repository, and one read-only audit. Capture live events, evidence, handoffs, REV, QA, replay, and human verdict.

**Exit:** accepted conformance evidence and human `PASS_FOR_P0_CONTROLLED_ACTIVATION`.

## Phase 2 — Agent Command Center and Durable Execution

Implement registries, session manager, durable workflow, host agent, runtime adapters, terminal gateway, intervention, and incident controls.

**Exit:** authorized sessions are observable, recoverable, scoped, and fail closed.

## Phase 3 — Bounded Mutation and Integration Candidates

Add workspace leases, runtime namespaces, temporary credentials, command/network policy, write-set reconciliation, freeze/review, immutable candidates, and human integration gateway.

**Exit:** one genuine low-risk mutation passes P1-A conformance; no production activation.

## Phase 4 — Evidence, Memory, and Project Knowledge

Implement evidence acceptance, project memory, decision and knowledge ledgers, retrieval authorization, temporal claims, and Context Builder.

**Exit:** cross-project leakage and raw-promotion tests pass.

## Phase 5 — SkillsHub and Governed Learning

Implement skill intake, packaging, evaluation, security review, restricted publication, consumption policy, monitoring, and revocation.

**Exit:** one low-risk skill is published from accepted evidence through human promotion.

## Phase 6 — MCP/A2A and Graph Intelligence

Implement registries, policy gateways, non-escalating delegation, knowledge/code/change-impact graphs, and cross-project firewalls.

**Exit:** every external invocation and delegation is attributable and auditable.

## Phase 7 — Restricted Operations, Production Governance, and Federation

Progressive delivery, release governance, rollback, resilience, outcome observation, portfolio dependencies, and approved cross-project knowledge/capability reuse.

**Exit:** separate production and federation conformance decisions.

## Phase 8 — Adaptive Intelligence

Only after sufficient accepted evidence and outcomes: model routing, dynamic team composition, predictive risk, workflow optimization, and bounded self-recovery. No self-activation.
