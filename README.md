# SecB

SecB is being rebuilt from a clean, local-first baseline.

- Repository: local only
- Default branch: `main`
- Version: `0.1.0-alpha.0`

Phase 0 establishes the operating constitution and machine-readable control contracts before runtime features are added. See [the documentation control center](docs/README.md).
